How to read it

The curve and the cost are related—not identical.

Sigma shows the noise level passed into each nominal sampling interval. A steep segment removes more noise at once.

Log + 0 expands the low-noise tail with a symmetric-log axis. It stays logarithmic above 1e-3, then uses a short linear zone so every curve reaches its real terminal zero.

Δsigma is the signed drop σᵢ − σᵢ₊₁. Peaks reveal where a schedule concentrates its movement.

Requested steps normally produces that many intervals. Solver choice can add model calls, so this is not a universal NFE counter.

Method

Generated, pinned, inspectable.

The Python generator reimplements the small scheduler formulas, verifies the registry and H3 settings against the pinned checkout, then writes the site data and all static assets.

The normalized tab is a declared canonical model-sampling object—not a claim that every scheduler is model-independent. Simple, DDIM, beta, normal, and SGM uniform depend on the supplied sigma table or timestep mapping.

Download the complete JSON dataset or inspect the generator. CI refuses to generate from a ComfyUI revision other than the repository pin.
